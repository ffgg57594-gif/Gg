Presenton LLM Gateway OpenAI-compatible base URL
GET + POST جاهزين لـ Presenton

Base URL تقدَر تلزقه في presenton.ai على طول

السكريبت الأصلي بيعمل POST على دالة Supabase. Presenton أول حاجة بيعمل GET على /api/v1/models عشان يجيب الموديلات، وبعدين POST على /api/v1/chat/completions. البوابة دي بتعمل الاتنين.

انسخ ده في Presenton → OpenAI Compatible URL

LLM=custom

أمثلة سريعة

# اكتشاف الموديلات (GET)
curl -s https://HOST/api/v1/models

# شات بـ GET
curl -s "https://HOST/api/v1/chat/completions?prompt=Tell%20me%20a%20joke"

# شات بـ POST (زي OpenAI)
curl -s https://HOST/api/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"model":"google/gemini-2.5-pro","messages":[{"role":"user","content":"Tell me a joke"}]}'
